# Pixel cloud world

## Layered animation revision

Production now uses `cloud-outpost-base.webp` (1536 × 1024) and `cloud-valley-base.webp` (2172 × 724). These clean plates remove the baked-in plants, trees, vines and clouds; the original assets below remain as references and are not imported by the application.

`PixelCloud.vue` renders 17 independent cloud groups. `PixelFoliage.vue` renders 73 independently anchored grass, shrub, tree and vine groups across the outpost, distant island and valley. Each uses staggered timing and root/top attachment points. The two clean plates were edited with the built-in ImageGen tool and converted to lossless WebP with alpha preserved.

The 19 valley trees mix five pixel silhouettes: pine, broad-crowned oak, pale-trunk birch, narrow cypress and drooping willow. Each style has a coordinated sage/olive/teal palette and keeps its own root-anchored sway; the center crop also includes varied trees on mobile.

The existing `animatedBackground` setting disables all descendant animations, including nested components. Reduced-motion preferences do the same. The terrain, buildings and viewport anchor remain stationary.
